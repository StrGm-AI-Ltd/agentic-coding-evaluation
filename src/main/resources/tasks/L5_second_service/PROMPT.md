# L5 — Split into services (budget 90 min)
Build three Spring Boot services — `account-service` (accounts, deposits, balances), `order-service` (`POST /orders` immediate fill, debiting the account through account-service's HTTP API), `market-service` (`GET /prices/{symbol}`: fixed table `AAPL 10.00`, `TSLA 250.00`, `EURUSD 1.0850`, 404 otherwise) — each with its own Gradle build (own `settings.gradle`), its own Postgres schema (no shared tables) and its own Flyway history, talking to each other only over HTTP. `docker compose up` starts all three plus PostgreSQL, each with a healthcheck reporting `healthy`; the account API is reachable at `localhost:8080` with `GET /health` → 200. Endpoints: `POST /accounts` → 201, `GET /accounts/{id}` → 200/404, `POST /accounts/{id}/deposits` → 200.
All money is `BigDecimal` or integer minor units — never float/double. Decimal JSON values are strings; timestamps are ISO-8601 UTC with millisecond precision (`2026-01-31T12:00:00.123Z`). Java 21, Spring Boot 3, Gradle, PostgreSQL via Flyway. Ship tests that run with `gradle test` in a clean container: a fresh PostgreSQL is provided through `SPRING_DATASOURCE_URL/USERNAME/PASSWORD` (tests may use it or run in memory; they must not need Docker or the network). Do not edit anything under `task/`. **This rung starts from an empty workspace: everything it names must be built here.**
