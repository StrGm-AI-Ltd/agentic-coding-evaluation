# L2 — Accounts against a fixed contract (budget 60 min)
Build an `account-service` exposing exactly: `POST /accounts` `{"currency":"USD"}` → 201 `{accountId, currency, availableBalance:"0.00"}`; `GET /accounts/{id}` → 200 `{accountId, currency, availableBalance, reservedBalance}` / 404; `POST /accounts/{id}/deposits` `{"amount":"100.00"}` → 200 `{availableBalance}` / 400 on a non-positive raw amount / 404; `GET /health` → 200 (any body). Serve on `localhost:8080` via `docker compose up` (service + PostgreSQL). Provide `openapi.yaml` declaring every path, method and status code above (no `default` responses).
**Bespoke rule (not in any tutorial):** deposits are rounded **ROUND_HALF_EVEN to 2 dp**; a deposit of `"0.005"` must read back as `"0.00"` and `"0.015"` as `"0.02"`.
All money is `BigDecimal` or integer minor units — never float/double. Decimal JSON values are strings; timestamps are ISO-8601 UTC with millisecond precision (`2026-01-31T12:00:00.123Z`). Java 21, Spring Boot 3, Gradle, PostgreSQL via Flyway. Ship tests that run with `gradle test` in a clean container: a fresh PostgreSQL is provided through `SPRING_DATASOURCE_URL/USERNAME/PASSWORD` (tests may use it or run in memory; they must not need Docker or the network). Do not edit anything under `task/`. **This rung starts from an empty workspace: everything it names must be built here.**
